# devdroid.club — контекст проекта

## Что это
Одностраничный сайт-презентация студии devdroid.club (d.d.c.) — full-cycle digital production: analysis, design, programming, testing.

## Стек и ограничения
- Статический сайт: один файл `index.html`, всё инлайном (CSS + JS внутри).
- Без сборки, без фреймворков, без зависимостей. Внешнее — только шрифт Hack с cdnjs.
- Сайт должен открываться просто двойным кликом по `index.html` или через `python3 -m http.server 8000`.

## Дизайн-система (не ломать без запроса)
- Стиль: terminal-style, минимализм. Чёрное на белом.
- Цвета: `--ink: #111111`, `--paper: #ffffff`.
- Шрифты: mono — Hack / DejaVu Sans Mono; sans — Helvetica Neue.
- Рамка-«фрейм» вокруг контента: `--frame-w: 2px`, chrome 56px, footer 56px, pad 24px.
- Любые новые элементы должны выдерживать эту эстетику: моноширинный текст, строгая сетка, никаких градиентов, теней и скруглений «по умолчанию».

## Правила работы
- Для любых изменений UI/дизайна — используй скилл hallmark (audit перед redesign).
- Перед крупной правкой — коротко опиши план, потом делай.
- После правок проверяй: страница валидна, ничего не уехало на мобильной ширине (360px), не появились лишние зависимости.
- Тексты на сайте — на английском, если не сказано иначе.
- Коммиты (если репо под git): краткие, на английском, по одному смыслу на коммит.

## Что считать «готово»
- Изменение видно и корректно в браузере на десктопе и мобильной ширине.
- Файл остался один (index.html), без новых внешних зависимостей.
- Стиль не выбивается из terminal-эстетики.
